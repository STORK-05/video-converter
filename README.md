# ビデオコンバーター (Video Converter Web)

iPhoneやAndroidのスマートフォン、PCのブラウザ上で100%完結する動画変換・編集Webアプリケーションです。

## 主な機能
- **画面録画カット**: iPhoneの上部（ステータスバー・Dynamic Island）や下部（ホームバー）を自動除去
- **画面サイズクロップ**: 16:9 / 9:16 / 1:1 / 自由比率
- **時間トリミング**: スライダーによる開始・終了時間の指定
- **フォーマット変換**: MP4, GIF, MP3 (音声抽出), WebM
- **ファイル圧縮**: 高圧縮・標準・高画質、解像度スケーリング (1080p, 720p, 480p)
- **プライバシー保護**: 外部サーバーへのアップロードは一切なし（完全ブラウザ内処理）
